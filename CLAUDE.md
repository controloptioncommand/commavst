# Правила проекта Comma

Comma — вайбкод VST3/AU/CLAP-эффект для macOS, C++ / JUCE 8: rack для экспериментов с высотой тона — микротональность (EDO, just intonation, строи Scala) и MPE-глайды. Ориентир по звуку — микротональная электроника вроде Aloboi. Брат Mist, Eido, Sumi, chrōma и Granula: те же темы, шрифты и страница About.
Репозиторий публичный: https://github.com/controloptioncommand/commavst

Перед любой работой с интерфейсом прочитай **[docs/DESIGN.md](docs/DESIGN.md)** — это обязательная дизайн-система.

## Версии и патчноуты
- Текущая версия — в файле `VERSION`. На странице About она же в `Source/UI/About.h` (`AboutInfo::version`, `AboutInfo::date`).
- Схема: этапы разработки — v0.1 (этап 0), v0.2 (этап 1) … ; v1 — когда звучат все модули. Дальше: минорный апдейт — число после точки +1 (v1.1, v1.2 …), мажорный — первая цифра. Какой апдейт какой, решает пользователь.
- **У каждой версии обязателен патчноут** `docs/releases/<версия>.md` — без него CI не соберёт релиз.
- Новая версия: поменять `VERSION` и `AboutInfo` → добавить патчноут → коммит в `main`. CI сам соберёт, проверит (pluginval, auval, тест) и опубликует релиз с архивом `Comma-macOS.zip`.
- Пока `VERSION` не меняется, новые сборки перезаписывают текущий релиз. Ветки `claude/**` только собираются (архив — в Artifacts сборки), релиз не публикуют.
- Ссылка на последнюю сборку: https://github.com/controloptioncommand/commavst/releases/latest/download/Comma-macOS.zip
- После публикации дать пользователю эту ссылку и команду установки:
  ```bash
  cd ~/Downloads && rm -rf Comma-macOS Comma-macOS.zip && gh release download -R controloptioncommand/commavst -p Comma-macOS.zip && unzip -q Comma-macOS.zip -d Comma-macOS && bash Comma-macOS/install-mac.sh
  ```

## Сборка и проверка
```bash
cmake -B build -DCOMMA_BUILD_TESTS=ON && cmake --build build --target CommaTest
./build/CommaTest_artefacts/Release/CommaTest ./render   # на Linux — через xvfb-run -a
```
На Linux для JUCE нужны пакеты `libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxext-dev libxcomposite-dev libfreetype6-dev libfontconfig1-dev libasound2-dev libgl1-mesa-dev`.
Тест: упаковка состава rack'а, математика rack'а на тестовых модулях (mix, bypass, параллельные группы, выравнивание задержки, смена состава без щелчка), проход без изменений, защита выхода и NaN, громкость, MIDI и MPE-каналы, моно, состояние (и мусорное), undo, пресеты, 40 бросков кубика, 44.1 / 48 / 96 кГц и блоки 1–4096, скорость, скриншоты в обеих темах, About. Перед коммитом тест должен печатать `ALL OK`. После изменений интерфейса — посмотреть скриншоты.

## Что нельзя ломать
- **Аудиопоток работает в реальном времени**: в `processBlock` и `Module::process` нет выделений памяти, блокировок, ввода-вывода. Буферы — в `prepare`. Параметры сглаживаются.
- Состав rack'а передаётся в аудиопоток одним 64-битным атомарным числом (`RackLayout::pack`); смена состава — затухание 5 мс, переключение, нарастание 5 мс.
- **Каждый модуль встречается в rack'е не больше одного раза**, все параметры заведены заранее, их ID (`doubler_mix` и т. п.) не меняются — иначе ломается автоматизация в проектах.
- Слот: `z = dry + mix · (wet − dry)`, dry задержан на задержку модуля. Группа: `(Σ wₖ·zₖ + d·x) / (Σ wₖ + d)`, `d = max(0, 1 − Σ wₖ)`. Слоты группы выравниваются по самому медленному; хосту сообщается сумма задержек групп. Bypass задержку не меняет.
- Модуль отдаёт «мокрый» сигнал (как при Mix 100 %); смешивание, bypass и выравнивание делает `Rack`.
- Выход: громкость, NaN → 0 со сбросом rack'а, мягкий предел — ниже 0.98 сигнал не трогается, выше упирается в 0 dBFS.
- Дробные задержки — не хуже кубической интерполяции (Hermite).
- Кубик не трогает Output, состав rack'а и bypass; Mix ≥ 40 %. Порядок слотов — только если включено в настройках (по умолчанию выключено).
- Пресет не трогает Output; свой пресет несёт состав rack'а.
- Изменение диапазонов параметров ломает старые проекты и пресеты — предупреждать.

## Этапы
0. ✅ Каркас: стек Mist, дизайн-система, пустой rack (слоты, bypass, mix, параллель), темы, About, название (v0.1).
1. Ядро строя (Scala .scl / .kbm — surge-synthesizer/tuning-library, N-EDO, отношения; единицы: центы / отношение / шаги), MTS-ESP, круг строя и анализатор.
2. Micro-doubler и Staircase delay на общем питч-шифтере (линия задержки, две головки со сдвигом на пол-окна, Ханн 20–60 мс).
3. Нотный слой MPE (Glide, Snap, характер скольжения, посадка, мод-матрица) и MPE-резонатор.
4. Frequency shifter с синхронизацией по темпу.
5. Scale harmonizer и микро-автотюн.
6. Varispeed.
7. Spectral mapper.

## Структура
- `Source/Rack/` — `Module` (интерфейс модуля), `Modules.cpp` (фабрика; этап 0 — заглушки), `Rack` (состав, mix, bypass, параллель, задержка)
- `Source/PluginProcessor`, `Params`, `Presets`, `Randomizer` — параметры, состав rack'а в состоянии (`Rack` → `Slot`: `module`, `parallel`), undo, шаблоны, кубик
- `Source/UI/` — `LookAndFeel`, `Widgets`, `About` (общие с братьями), `MainView` (круг строя), `RackView` (слоты)
- `Tests/CommaTest.cpp` — офлайн-тест; `scripts/` — установка и проверка приватности; `docs/` — дизайн, картинки README, патчноуты
- При изменении ручек и поведения — обновлять README (пасхалки там не упоминать), а с этапа 2 и руководство.
